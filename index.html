    Einstellungen

    Alles bleibt nur auf diesem Gerät gespeichert. Der Groq-Schlüssel ist Jarvis’ Denkmotor – ohne ihn kann er nicht antworten.

    So legst du den GitHub-Token an
    1. Link oben öffnen (GitHub, eingeloggt).
    2. Name: „Jarvis-App“, Ablauf: 1 Jahr.
    3. „Only select repositories“ → jarvis.
    4. Berechtigungen: Actions, Contents, Issues jeweils „Read and write“.
    5. „Generate token“, kopieren, hier einfügen, Speichern.
